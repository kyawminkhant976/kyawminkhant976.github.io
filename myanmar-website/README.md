# Myanmar - The Golden Land

Bilingual (English / Chinese) website about Myanmar: map and flag, 15 regions, introduction, travel guide, cost calculator, language section, quiz and chatbot.

## Files
- index.html - page structure
- css/style.css - styles (black and gold theme)
- js/main.js - language switch, calculator, quiz, chatbot, pop-ups
- images/ - photos

## Run locally
Open index.html in a browser (or use the VS Code "Live Server" extension).

## Publish on GitHub Pages
1. Push all files to a GitHub repository.
2. Repo Settings > Pages > Deploy from a branch > main / root > Save.
3. Your site will be at https://YOUR-USERNAME.github.io/REPO-NAME/

## Note on the chatbot
Inside Claude the chatbot uses AI. On GitHub Pages it falls back to built-in answers for common topics (food, Thingyan, religion, capital, best time, trip plan, cost, history).
